# Applications

Each directory is something that runs. Libraries live in [`packages/`](../packages).

| App | License | What it is |
| --- | --- | --- |
| [`web`](web) | AGPL-3.0 | Browser application: Home, Transactions, Accounts, Reports, Settings |
| [`api`](api) | AGPL-3.0 | Application API and single-file local service (`rastrata-service`) |
| [`terminal`](terminal) | MIT | Go CLI and full-screen terminal client (`rastrata`) |
| [`mcp`](mcp) | MIT | Model Context Protocol (MCP) adapter over the application API |
| [`ledger-service`](ledger-service) | AGPL-3.0 | Durable Object ledger Worker runtime |
| [`ledger-acceptance`](ledger-acceptance) | AGPL-3.0 | Synthetic ledger verification Worker |
